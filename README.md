# AcadPro - College Form Auto-Filler

**AcadPro** is a modern Chrome Extension (Manifest V3) designed to automatically detect and fill college web portal feedback forms, course evaluation surveys, and faculty questionnaires.

## Features

- ⚡ **Instant Radio & Dropdown Filling**: Choose rating preferences (*Excellent*, *Good*, *Varied*, *Neutral*) to automatically check radio buttons and select dropdown options.
- 💬 **Smart Text & Comment Filling**: Auto-fill text fields and textareas using customizable comment presets, custom text, or AI contextual suggestions.
- 🚀 **Auto-Submit & Navigation**: Option to automatically click `Submit` or `Next >>` buttons.
- 🎨 **Modern Sleek UI**: Built with a dark mode glassmorphism popup interface and instant toast notifications.

## Installation

1. Clone or download this repository.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select this directory.

## Testing

Open `test_form.html` in Chrome to test the extension on replicated college feedback forms.
